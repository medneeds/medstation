- Intern courtesies are granted only through an admin-checked server function that reuses the single courtesy row per user and sends the welcome email itself; this keeps grant and email in one place and stops the browser choosing recipients.
- Admin billing treats active paid one-time purchases (annual and Pix 30 days) as paying records through admin-list-subscribers/one-time.ts, and a signup trigger links purchases made before account creation by email; the annual plan is a one-time payment, not a Stripe subscription, so subscription-only counts miss it.

- The Arsenal Med annual bonus is registered by push-plus-verify: stripe-webhook notifies the Arsenal Med site with the payment reference and that site confirms it through the public arsenal-bonus-verify function; failed notices are replayed for all current annual subscribers through the admin-only admin-resend-arsenal-bonus function, so this links two separate projects without sharing a secret.
- The first Meta Pixel PageView is sent inline from index.html (same public path list as analytics.ts) and trackPageView skips that one via window.__msInitialPixelPageView; this counts ad clicks as landing views without waiting for the app bundle, and the Google Fonts stylesheet loads non-blocking for the same reason.
- index.html carries a static copy of the "/" header and first section (same Tailwind classes as Lp3/LeadForm, removed on other paths) plus an early theme script; clicks and typed e-mail before the app mounts are stored in window.__msShell and replayed via src/lib/landingShell.ts.
